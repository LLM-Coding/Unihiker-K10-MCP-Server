== Unihiker-K10-MCP-Server

This repository currently contains the implementation of a http MPC-Server for the Unihiker-K10 development board, written in Python.

Since the Wifi and ML features do not work together in MicroPython, the MCP-Server is not capable of using the AI/ML features of the Unihiker-K10 board.

It is planned to add another implementation as Arduino project.
